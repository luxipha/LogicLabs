# Earthquake coding images

Seven cumulative stages. PNGs are 2400 × 1800. SVGs are editable sources.

Regenerate from repository root: `node scripts/generate-earthquake-coding.mjs`.

These are MakeCode-style teaching diagrams, not editor screenshots or an importable program. Block category colors and nesting are consistent throughout. The final stage includes the Running guard and 5000 ms shaking cycles.
