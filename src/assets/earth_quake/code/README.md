# Earthquake coding images

Seven close-up cards (1600 × 900) and seven complete-program references (2400 × 1700).

All block artwork in rendered/ is exported by Microsoft MakeCode's documented renderblocks API with the official ELECFREAKS Nezha V2 extension. This artwork is not hand-drawn. Each export includes its exact TypeScript source and authentic SVG. provenance.json records the renderer and extension.

Refresh artwork: node scripts/render-earthquake-blocks.cjs
Compose cards offline: node scripts/generate-earthquake-coding.mjs

Close-ups are excerpts. Use Full program for the complete sequence and placement. The final close-up omits the existing warning/loop; the full reference includes them.
